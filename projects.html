Projects

Here are some of the projects I have worked on over the years:

Active Directory Home Lab

Built a Windows Server Active Directory environment with domain-joined Windows clients.

This Active Directory home lab simulates a small enterprise Windows domain environment using virtual machines. The environment was built to practice common Windows Server administration, Active Directory management, Group Policy, DNS, file sharing, and troubleshooting tasks.

3D Room Replica Model - Maya

A 3D modeled room recreation completed in Autodesk Maya using real-world reference images. This project served as my introduction to 3D modeling, texturing, and industry standard best practices.

This project was completed as part of learning Autodesk Maya and the fundamentals of 3D modeling. Using only reference images of a real-world room, I recreated the environment by modeling each object individually and assembling them into a complete 3D scene. Throughout this project, I gained hands-on experience with the complete 3D asset creation workflow, including polygon modeling, UV mapping, texturing, material creation, and applying normal maps. Recreating an existing room challenged me to accurately match proportions, scale, and layout while developing an understanding of industry-standard modeling practices.

Robotic Arm 3D Rig - Maya

Rigged a robotic arm in Maya to learn how to rig a 3D model while following industry standard best practices.

A robotic arm rig created in Autodesk Maya to learn the fundamentals of 3D rigging, skeletal hierarchies, and animation controls. This project focuses on building a functional rig using industry-standard techniques, including joint placement, inverse and forward kinematics, and control objects. The goal of this project was to understand how 3D models are prepared for animation by creating a complete rig from scratch. The robotic arm provided a simple mechanical model that allowed me to focus on rigging concepts without the added complexity of character deformation.
